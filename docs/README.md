# Documentation

Welcome to the Atlas documentation. This manual provides a cohesive overview of the framework’s architecture, configuration, deployment, and underlying philosophy.

Atlas is a modern, self-hosted API infrastructure toolkit designed for minimal friction and strong provider isolation. It powers search, finance, and news aggregation using a decoupled infrastructure design.
